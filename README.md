# 苍蝇头勇者传

手机横屏打开即玩的七关冒险小游戏。

## 玩法

左摇杆移动，右侧按住开火、防御并施放技能。每过一关选择一次强化，进度保存在当前浏览器。

电脑：WASD 或方向键移动，F 开火，空格防御，Shift 机动，E 战术，Q 大招，C 急救，Esc 暂停。
